# Triage Labels

相关技能使用五种标准 triage 角色。本文件将这些角色映射到仓库 issue tracker
实际使用的 label 字符串。

| Label in mattpocock/skills | Label in our tracker | Meaning                                  |
| -------------------------- | -------------------- | ---------------------------------------- |
| `needs-triage`             | `needs-triage`       | Maintainer 需要评估该 issue  |
| `needs-info`               | `needs-info`         | 等待报告者补充信息 |
| `ready-for-agent`          | `ready-for-agent`    | 规格完整，可交给 AFK agent 处理 |
| `ready-for-human`          | `ready-for-human`    | 需要人工实施 |
| `wontfix`                  | `wontfix`            | 不会处理 |

当技能提到某个角色（例如原文 `apply the AFK-ready triage label`）时，使用表中对应的
label 字符串。

右侧列应与仓库实际使用的词汇保持一致。

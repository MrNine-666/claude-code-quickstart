# 重构 TUI Skills 列表布局与批量操作

## Goal

让 Skills 已安装列表在大量条目和多来源场景下更易浏览、定位和批量维护，同时保持默认操作路径简单直接。

## Background

- 当前 Skills 已安装列表采用平铺展示。
- 安装页已经使用 `name（source）` 的来源标识形式。
- 用户要求保留平铺视图，并新增按 source 分组、可展开/收缩的视图。
- 当前工作区中的已安装领域模型已经按 `(name, sourceIdentity)` 区分逻辑实例，
  `source` 与 `sourceUrl` 分开保存，最终状态以完整 `skills list -g --json` 复检为准。
- 当前列表仍为双列 Card 网格；光标索引针对过滤后的列表，尚无已安装条目的多选状态。
- 当前 `a` 同时注册为安装页“全选”和列表页“更新全部”；`u` 更新当前条目，`d`
  卸载当前条目。现有 keybinding registry 与 footer 可按子模式复用同一物理键。
- 现有 `openUrl()` 只允许 http/https，并已由 Tools 页复用；Skills 列表尚无鼠标点击
  或快捷键打开来源的交互。
- 未知来源条目按现有能力矩阵只能删除，不能更新；批量操作必须保持这条安全边界。

## Requirements

- R1：已安装列表提供两种布局：平铺、按 source 分组。
- R2：默认使用平铺布局，作为按 Skill 名称浏览和批量维护的低认知成本入口；按
  source 排查或维护时可通过快捷键切换为分组布局。
- R3：两种布局均改为单列，每个 Skill 条目占三行：
  - 第一行：平铺模式显示 `name（source）`；分组模式只显示 `name`。
  - 第二行：存在可直接打开的 `sourceUrl` 时显示该 URL，并支持点击或快捷键跳转；
    不存在时固定显示“无来源链接”，且不能触发打开。
  - 第三行：显示 Claude Code 与 Codex 的安装状态。
- R4：分组模式以 source 为组，组可展开和收缩；所有未知来源 Item 统一放入一个
  “未知来源”展示组，但仍保持各自独立的逻辑实例身份。
- R5：列表支持多选；选中多个 Skill 后可批量更新和批量卸载。
- R6：移除“更新全部”功能。
- R7：将 `a` 快捷键改为“全选 / 全部取消”。它作用于当前过滤结果；分组收缩只
  改变展示，不从全选范围中排除匹配条目。无过滤时范围为全部已安装条目。
- R8：布局切换、多选和批量操作不得破坏现有 Skills 来源拓扑、共享安装状态与 Claude Code/Codex 状态投影契约。
- R9：列表页快捷键固定为：`v` 切换布局、`o` 打开当前 Skill 的来源链接、
  `e` 全部展开/收起来源组、`Space` 选择/取消当前 Skill、`a` 全选/全部取消当前过滤结果。`u`/`d` 在存在
  多选时操作选中项，否则保持操作当前项。分组标题聚焦时，`Enter` 或 `Space`
  展开/收缩。`e` 只在分组布局的 footer 中展示。

## Acceptance Criteria

- [ ] AC1：首次进入已安装 Skills 列表时默认显示平铺、单列布局。
- [ ] AC2：快捷键可在平铺与按 source 分组布局之间切换；切换后条目内容符合 R3。
- [ ] AC3：分组布局可逐组展开和收缩，并正确呈现各 source 下的 Skills；所有未知
      来源 Item 统一显示在“未知来源”组中，且不会因展示分组而被合并为同一 Item。
      `e` 可收起所有来源组，并在全部已收起时再次按下以全部展开。
- [ ] AC4：每个条目第二行存在 `sourceUrl` 时展示该 URL，鼠标点击和对应快捷键均能
      触发跳转；不存在时展示“无来源链接”，点击和快捷键均不打开地址。
- [ ] AC5：每个条目第三行同时展示 Claude Code 与 Codex 安装状态，且与真实检测状态一致。
- [ ] AC6：用户可选择多个 Skill，并对选中项执行批量更新或批量卸载。
- [ ] AC7：`a` 可全选当前过滤结果或在这些结果已全选时全部取消；收缩组中的匹配
      条目仍在作用范围内；界面不再提供“更新全部”。
- [ ] AC8：类型检查、Skills 相关契约验证及仓库要求的质量门禁通过。
- [ ] AC9：快捷键处理与 footer 均来自集中 keybinding registry，且符合 R9；过滤框、
      Modal 或 busy 状态不会误触发背景列表动作。

## Out of Scope

- 不改变 Skills 安装页的安装流程与批量安装契约。
- 不改变 `.agents/skills`、`.claude/skills` 及共享状态投影的底层存储拓扑。
- 不新增新的上游 Skills CLI 能力。

## Technical Notes

- Tools 页已有 `o` + `openUrl()` + OSC-8 `<a href>` 的链接模式，Skills 应复用。
- 批量更新仍受上游名称级 `skills update <names...>` 契约约束，不能宣称来源级隔离。
- 批量卸载必须继续以完整 `InstalledSkillItem` 快照和来源隔离 planner 为边界，不能
  退回按名称直接删除。
